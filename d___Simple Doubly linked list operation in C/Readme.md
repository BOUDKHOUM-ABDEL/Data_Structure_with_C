✨ **Welcome to the Doubly Linked List Wizard!** ✨

    Step into the magical realm where data flows in two directions! With this spellbinding program, you’ll master the 
    art of **Simple Doubly Linked Lists**, granting you the power to navigate and manipulate nodes like a true wizard. 🧙‍♂️

Key Features (a.k.a. Spells 🪄):

       🔄 Bi-directional Magic: Traverse your doubly linked list forwards and backwards! (Each node knows its predecessor and successor).
       📜 Summon Nodes: Add new nodes to the beginning or the end of your list with a simple incantation.
       ❌ Banish Nodes: Remove troublesome nodes from the start or end swiftly.
       👀 Reveal the List: Display the contents of your list in a clean, magical format to see your spells at work.
       🛡️ Error Protection: Thoughtful handling of edge cases, like trying to delete from an empty list.
       🧹 Memory Mastery: Ensures memory is dynamically allocated and deallocated properly—no memory leaks in this enchanted realm! 💧

Follow the wizard's menu to command your doubly linked list:

    ------------------------🪄 MENU 🪄------------------------
     1. Add a node at the beginning. 🪄
     2. Add a node at the end. 🔚
     3. Delete a node from the beginning. ❌
     4. Delete a node from the end. 🗑️
     5. Display the list. 👀
     6. Exit the wizardry. ✨
    --------------------------------------------------------
